# Следующий SEO-пакет: «Item-страница отвечает на запрос паттерна»

## Почему этот пакет
- Единственный наблюдаемый органический спрос, который VibeUI уже получает, — длинный хвост «<паттерн> ui/react» на item-страницах: на `.club` за 24.09–14.10 показы у 251 страницы, 10 из 13 кликов — items (GSC). На `.ru` — 418 страниц с показами (07.09–13.10).
- В выдаче по таким запросам (`avatar stack react`, `macos dock react component`, `mega menu react tailwind`) стоят именно страницы одного компонента; у них есть тип и стек в title, Usage, Props, связанные компоненты.
- Нужные данные у VibeUI уже есть почти на 100 % (`ai.usage`, `controls`, `registryDependencies`, сценарии), но не выводятся.
- Головные запросы (`tailwind components`, `react компоненты`, `шаблоны сайтов`) заняты библиотеками-гигантами и статьями-подборками — в этом релизе не цель.

### Отложено как неподтверждённое
- «Похожие items» по тегам (качество неровное, сайдбар уже связывает категорию).
- Статья «вайбкодинг: что это» (большой RU-спрос, но информационный и вне шаблона item'а).
- Страницы под «шаблоны сайтов» / «landing page template» (интент «скачать шаблон», продукт отвечает иначе).
- Отдельная страница «shadcn registry» (нет данных о спросе и выдаче).
- FAQ-блоки на items (у конкурентов — текст ради объёма).

## Зависимости и риски
- Правило проекта: билд/линт/тайпчек — только по команде владельца; проверка — `meta:validate` и браузер, типы ловит CI.
- Шаблон общий для 4096 URL: ошибка видна сразу везде. Смягчение — сверка 6 примеров на обоих доменах до пуша.
- Смоук `deploy.yml` проверяет рендер item'а по slug — ассерты не должны зависеть от `<title>`; сверить перед пушем.
- Размер HTML: R2–R5 добавляют ≈ 0,5–2 КБ на страницу.
- Изменение title сбросит часть накопленного у Google сниппета — на объёме ≈ 500 показов в месяц это малый риск.

## Критерии приёмки
1. 6 примеров из ITEM-PAGES §4 на `vibeui.ru` и `vibeui.club` (view-source): title нового вида; разделы R2–R5 присутствуют там, где есть данные, и отсутствуют там, где данных нет (`hero-001` без usage, `button-anim-002` без связей).
2. Все ссылки разделов R4/R5 на выборке — 200 и ведут на тот же домен.
3. Ни одного нового раскрытия исходника: в HTML Pro-item'а нет кода файла (только usage, который и так в RSC-payload).
4. `npm run meta:validate` зелёный; смоук CI зелёный после деплоя.
5. Mobile 375 px и desktop: разделы не ломают раскладку на `hero-001`, `button-015`.
6. Rich Results Test: JSON-LD `SoftwareSourceCode` и `BreadcrumbList` без ошибок.
