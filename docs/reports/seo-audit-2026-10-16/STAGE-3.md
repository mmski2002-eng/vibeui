## 2. Sitemap

Проверено 2026-10-17 на обоих доменах. Полный обход не делался — сверка множеств и целевая выборка.

| Проверка | vibeui.ru | vibeui.club |
|---|---|---|
| HTTP, тип | 200, `application/xml` | 200, `application/xml` |
| Ответ ботам (Googlebot / YandexBot UA) | 200; TTFB 0,17 / 0,14 с; полная отдача 2,5 / 0,26 с | 200; TTFB 0,58 / 0,27 с |
| Размер, URL | 979 КБ, 2173 | 983 КБ, 2173 |
| XML (`ElementTree`) | валиден | валиден |
| Дубли `<loc>`, чужой хост, `/`, `?`, верхний регистр, `/en/` | 0 | 0 |
| `lastmod`: пусто, неверный формат, будущие даты | 0 | 0 |
| hreflang: свой URL в alternates, пара ru+en, взаимность между доменами | у всех 2173 / взаимно | у всех 2173 / взаимно |
| Набор путей одинаков на двух доменах | да | да |
| Соответствие каталогу | 2048 items = 2048 в registry; лишних нет | то же |
| Слитые категории (92 старых адреса с 301) в sitemap | 0 | 0 |
| Выборка статусов: все не-item URL (124) + 60 случайных items | 184/184 → 200, без 3xx | 184/184 → 200 |
| `lastmod` против git | совпадает: `error-404-001` — 16.10, `hero-001` — 22.09, `navbar-046` — 15.10 | то же |

**Найдено и исправлено.** Категории получали lastmod только от своих items. Заголовок и вводный текст категорий живут в `lib/landing-copy.ts`, поэтому их правка не меняла lastmod. Пример: у `/blocks/hero` текст изменился 16.10, а в sitemap стоит 15.10.

Исправление в [scripts/build-lastmod.mjs](../../../scripts/build-lastmod.mjs): дата последнего коммита `lib/landing-copy.ts` участвует в lastmod категории. Прогон генератора: категории получают дату файла текстов, даты items не меняются. Сам `registry/generated/lastmod.json` в коммит не входит — CI пересобирает его в `npm run build`.

Ограничение: правка текста любой категории сдвигает lastmod всех категорий. Сейчас это точно (меняются все), дальше — с запасом. Делить файл ради точности пока незачем.

**Ложная тревога, снята.** В первой выборке не было `/animations/error-404` — фильтр по `-NNN$` отсёк «-404». Категория в sitemap есть.

**«Временная ошибка при обработке» в GSC.**
- Ни одной ошибки в sitemap сейчас не воспроизводится: ответ 200, XML валиден, URL актуальны, все пары ru/en на месте.
- В этапе 2 кабинет показывал sitemap «Успешно», последнее чтение — 03.10.
- Вывод: ошибка была временной на стороне чтения Google, причина в файле не подтверждена. Наблюдение: полная отдача sitemap Googlebot-у заняла 2,5 с против 0,26 с у YandexBot-а на тот же файл. Это единичный замер — нужно повторить, прежде чем что-то менять.
- Дробить sitemap оснований нет: 2173 URL при лимите 50 000.
