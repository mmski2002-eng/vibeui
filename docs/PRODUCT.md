# PRODUCT

## Что такое VibeUI

Библиотека UI-компонентов, спроектированная не под ручной копипаст, а под передачу
AI-агенту. Каждый компонент — это не только код, но и структурированная инструкция:
как поставить, что сохранить, что можно менять.

Принцип: **«Выбери дизайн → отдай ИИ → получи сайт.»**

## Для кого

Люди, которые собирают сайты через AI-агентов (Claude Code, Cursor, ChatGPT и др.):
инди-разработчики, вайбкодеры, дизайнеры без глубокого фронтенда, небольшие команды
на ранней стадии продукта.

Не для: команд с собственной дизайн-системой и штатным фронтендом.

## Проблема

Объяснить агенту нужный дизайн словами — дорого и ненадёжно. Пользователь пишет
«современный минималистичный hero», получает generic-результат, правит промпт,
получает другой generic-результат. Визуальный выбор быстрее описания.

Вторая часть проблемы: даже когда пользователь нашёл готовый компонент, агент часто
не ставит его, а «пересоздаёт по мотивам» — теряя анимации, spacing и responsive.

## Ключевой сценарий

```
каталог → страница компонента с live preview → Copy for AI
        → пользователь вставляет в агента → агент ставит компонент
        → результат совпадает с preview
```

Успех сценария = результат в проекте пользователя визуально совпадает с preview
в каталоге. Это единственная метрика, которую доказывает MVP.

## Отличие от обычной component library

| Обычная library     | VibeUI                                                          |
| ------------------- | --------------------------------------------------------------- |
| Copy code           | Copy for AI — код + инструкция для агента                       |
| Docs для человека   | Metadata для агента: deps, install, что сохранить               |
| Ты интегрируешь сам | Интегрирует агент, задача каталога — не дать ему сфантазировать |
| Единица — компонент | Единица — воспроизводимый блок страницы                         |

Формат registry намеренно shadcn-совместимый: агенты уже умеют с ним работать,
своё изобретать не нужно.

## Границы MVP

Входит: каталог, live preview, страницы компонентов, Copy for AI,
shadcn-compatible registry, несколько демонстрационных компонентов.

Не входит: auth, billing, subscriptions, referrals, marketplace, MCP,
visual builder, собственный AI, database.

Правило: пока сценарий выше не работает end-to-end, любая другая функция —
не приоритет. Данные каталога статические, из кода. Бэкенда нет.
