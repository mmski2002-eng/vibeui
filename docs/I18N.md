# I18N — русский и английский

Сайт двуязычный. Русский базовый, английский полный: интерфейс, метаданные
items и обе инструкции для агента.

## Маршруты

Русский живёт в корне, английский под `/en`:

| Русский              | Английский              |
| -------------------- | ----------------------- |
| `/`                  | `/en`                   |
| `/components`        | `/en/components`        |
| `/blocks`            | `/en/blocks`            |
| `/components/<slug>` | `/en/components/<slug>` |

Префикса у русского нет намеренно: `/c/`-ссылки уже разошлись наружу, и
переезд корня в `/ru` сломал бы их. Тела страниц живут в
`components/pages/`, файлы маршрутов — тонкие обёртки, которые передают
только `locale`.

Переключатель в шапке (`components/catalog/locale-switch.tsx`) ведёт на ту
же страницу в другом языке, а не на главную: человек читает конкретный
компонент и хочет прочитать его же.

## Словари

- `lib/i18n.ts` — интерфейс сайта;
- `lib/i18n-prompt.ts` — каркас обеих инструкций для агента.

Английский написан заново, а не переведён построчно. Для промпта это не
стилистика: его читает модель, и калька с русского даёт формулировки,
которым агент следует хуже, чем идиоматичным.

## Метаданные items

Русский лежит в обычных полях, английский — в `meta.i18n.en`. Переводится
`description`, `ai.summary`, `ai.preserve`, `ai.adapt`, `ai.notes`,
`ai.usage` и подписи контролов. `title` у всех items уже английский.

`lib/localize.ts` накладывает перевод один раз на входе, поэтому всё ниже —
генератор промпта, сниппет, панель контролов — про язык ничего не знает.

**Незаполненное поле откатывается к русскому.** Честный оригинал лучше
машинного перевода, а пропуск сразу видно.

## Подписи по умолчанию внутри компонентов

Они русские (`"Отменить"`, `"Скачать отчёт"`) и такими остаются: это
исходник, который пользователь устанавливает, и менять его ради витрины
нельзя — файл обязан оставаться побайтово тем же.

Английская витрина задаёт их через `meta.i18n.en.controls.<prop>.default`.
Значение уезжает в сниппет явным пропом, поэтому агент вставляет
английский текст, не трогая установленный файл.

Следствие: у английской версии сниппет всегда содержит подпись явно, даже
когда пользователь ничего не настраивал.

## Инструкции для агента

Язык приезжает в `?lang=en`:

```
https://vibeui.ru/c/button-001?lang=en
https://vibeui.ru/c/button-001?lang=en&tone=soft&children=Buy%20now
```

Параметр добавляют карточка и страница item'а, когда человек читает
английскую версию. Без параметра отдаётся русский бриф — старые ссылки
работают как работали.

Ссылка на страницу компонента внутри брифа тоже ведёт в нужную языковую
версию.

## Чего не хватает

Русский и английский — всё. Третий язык потребует решить, что делать со
словарями: сейчас они плоские объекты, и при трёх языках их стоит
разложить по файлам. Раньше этого не трогать.
