# Карта демо-фотографий

Что на каком файле в `public/demo/`. Составлено просмотром всех кадров —
чтобы подбирать картинку под товар по списку, а не открывать 142 файла заново.

Правило подключения: путь к файлу живёт только в `meta.preview.props`
(демо-данные каталога). В сам блок демо-пути не попадают — установленный
компонент не должен ссылаться на файлы VibeUI.
