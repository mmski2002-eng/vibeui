# Аудит фирменного цвета в компонентах

Дата: 12 сентября 2026. Проверено 71 категория компонентов, 1182 items,
по миниатюрам каталога в режиме «Обзор» на тёмной подложке. Порядок —
по русскому алфавиту категорий.

Фирменный акцент: `oklch(0.6803 0.2144 39.8)`. Его несут ~905 компонентов.
В подавляющем большинстве он стоит на месте: первичное действие, активный
пункт, выбранное значение, заливка ползунка, ссылка. Ниже — только то, где
оранжевый работает против смысла.

## Критерий

Фирменный цвет неуместен, когда он заменяет **семантический**:

- ошибка, удаление, отрицательное число → красный;
- успех, «готово», «свободно» → зелёный;
- подтверждено, информация → синий;
- предупреждение, staging, «истекает» → янтарный;
- нейтральный контент (чипы тегов, коды, счётчики порядка) → серый.

Предлагаемые значения в палитре проекта:

| Роль | Значение |
|---|---|
| Красный | `light-dark(oklch(0.58 0.2 25), oklch(0.72 0.19 25))` |
| Зелёный | `light-dark(oklch(0.55 0.15 150), oklch(0.75 0.17 150))` |
| Синий | `light-dark(oklch(0.55 0.15 250), oklch(0.72 0.14 250))` |
| Янтарный | `light-dark(oklch(0.7 0.16 80), oklch(0.82 0.16 85))` |
| Нейтральный чип | `color-mix(in oklab, var(--fg) 10%, transparent)` + текст `fg` |

## Как править

Каждый item несёт свою палитру `--vibeui-<name>-*`. Замена — одна-две
переменные в `STYLES` файла компонента, без общих токенов. После
согласования списка правлю по категориям, каждая — отдельным коммитом.

Скриншоты аудита: `.playwright-mcp/audit/` (в git не попадают).
