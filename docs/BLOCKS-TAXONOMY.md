# Таксономия блоков для сайтостроения

Справочник «какие блоки вообще бывают», собран без оглядки на текущий
каталог — для сверки и планирования. Дата: 2026-09-06.

## 1. Ядро лендинга (маркетинг)

- **Hero** — первый экран: заголовок, подзаголовок, CTA, медиа/скриншот.
  Подвиды: с формой, с видео, с product-скриншотом, split (текст|медиа),
  с бегущей строкой логотипов, с анимированным фоном.
- **Navbar / Header** — навигация, мега-меню, с CTA, с анонс-баром сверху.
- **Announcement bar** — тонкая полоса промо/новости над шапкой.
- **Logo cloud / Social proof strip** — «нам доверяют»: логотипы клиентов,
  счётчики, рейтинги (G2, Trustpilot).
- **Features** — сетка/список преимуществ. Подвиды: иконки-сетка,
  чередующиеся секции (zigzag: текст|скриншот), bento-grid, табы с фичами,
  сравнение «до/после».
- **How it works / Steps** — 3–4 шага процесса, нумерация, таймлайн.
- **Product showcase / Screenshot tour** — крупные скрины с аннотациями,
  карусель экранов, интерактивное демо.
- **Stats / Metrics** — большие числа: пользователи, аптайм, экономия.
- **Testimonials** — отзывы: карточки, карусель, стена твитов, видео-отзыв,
  один крупный quote с фото.
- **Case studies / Success stories** — карточки кейсов с результатами.
- **Pricing** — тарифы: 2–4 плана, переключатель мес/год, сравнительная
  таблица фич, калькулятор, enterprise-CTA.
- **FAQ** — аккордеон, две колонки, с поиском.
- **CTA section** — финальный призыв: полоса с кнопкой, с фоном, с формой.
- **Footer** — колонки ссылок, подписка, соцсети, язык/валюта, legal.

## 2. Захват и коммуникация

- **Newsletter / Subscribe** — email-форма (inline, секция, попап-вид).
- **Contact** — форма обратной связи, карта, реквизиты, каналы связи.
- **Lead capture / Signup** — регистрация, ранний доступ, waitlist.
- **Booking / Scheduling** — запись на демо/встречу, выбор слота.
- **Download / App badges** — App Store/Google Play, QR-код.
- **Chat prompt / Support teaser** — «напишите нам», виджет-заглушка.

## 3. E-commerce

- **Product grid / listing** — сетка товаров с фильтрами и сортировкой.
- **Product card** (как блок-витрина) — фото, цена, рейтинг, быстрые действия.
- **Product detail** — галерея, варианты, размерная сетка, добавить в корзину.
- **Cart / Mini-cart** — корзина, drawer-корзина.
- **Checkout** — шаги оплаты, форма адреса, способы доставки/оплаты.
- **Collection / Category banner** — промо категории.
- **Sales / Promo** — скидочный баннер, countdown-таймер акции, промокод.
- **Reviews** — отзывы о товаре с фото и рейтингом.
- **Order tracking / status** — статус заказа по шагам.
- **Related / Recently viewed** — рекомендательные полки.
- **Size guide / Comparison** — сравнение товаров, таблица характеристик.

## 4. SaaS / приложение (внутренние экраны)

- **Auth** — вход, регистрация, восстановление, 2FA, magic link, OAuth.
- **Onboarding** — приветственные шаги, чек-лист прогресса, тур.
- **Dashboard** — сводка: карточки метрик, графики, ленты активности.
- **Settings** — профиль, безопасность, уведомления, биллинг, команда.
- **Billing / Plans** — текущий план, использование, инвойсы, апгрейд.
- **Team / Members** — список участников, роли, приглашения.
- **Notifications center** — лента уведомлений, фильтры, отметить всё.
- **Search results** — выдача с фасетами.
- **Activity feed / Audit log** — хронология действий.
- **Integrations** — каталог подключений с тумблерами.
- **API keys / Developer** — ключи, вебхуки, документация-тизер.
- **Empty states** — пустые экраны с CTA.
- **Error pages** — 404, 500, maintenance, offline.
- **Kanban / Tasks** — доска задач (как блок-витрина).
- **Data table** — таблица записей с массовыми действиями.
- **File manager / Uploads** — списки файлов, дропзона.
- **Wizard / Multi-step form** — мастер настройки.

## 5. Контент и медиа

- **Blog listing** — карточки статей, featured-статья, по тегам.
- **Blog post** — тело статьи: заголовок, оглавление, автор, шаринг.
- **Author bio** — карточка автора.
- **Table of contents** — липкое оглавление.
- **Gallery / Portfolio** — masonry, фильтруемая сетка работ.
- **Video section** — плеер с постером, плейлист.
- **Podcast / Audio** — эпизоды с плеером.
- **Docs / Knowledge base** — сетка разделов помощи, поиск по докам.
- **Changelog / Release notes** — версии с тегами изменений.
- **Roadmap** — публичный роадмап: колонки planned/in progress/done.
- **Events / Webinars** — афиша, карточка события, регистрация.
- **Press / Media kit** — упоминания в прессе, ассеты бренда.

## 6. Люди и доверие

- **Team** — сетка команды с фото и соцсетями.
- **About / Mission** — история, ценности, таймлайн компании.
- **Careers / Vacancies** — список вакансий по отделам.
- **Community** — цифры сообщества, ссылки на Discord/Telegram.
- **Partners / Affiliates** — партнёрская программа.
- **Security / Compliance** — SOC2/GDPR-бейджи, практики безопасности.
- **Legal** — оформление TOS/Privacy (типографика длинного текста).

## 7. Спец-механики

- **Comparison vs competitors** — «мы против X», таблица галочек.
- **Calculator / ROI** — интерактивный расчёт выгоды.
- **Quiz / Survey** — опрос с шагами.
- **Countdown / Launch** — таймер запуска, «скоро».
- **Cookie / Consent** — плашка согласия.
- **Language / Region switcher** — выбор локали как блок.
- **Referral** — «пригласи друга».
- **Banner-carousel** — ротатор промо.
- **Mega footer sitemap** — развёрнутая карта сайта.

## Сверка с каталогом (2026-09-06)

Есть 15 категорий, 390 блоков: hero 19, navbar 16, features 18, pricing 19,
testimonials 6, faq 6, cta 6, footer 8, blog 6, contact 6, ai 20, auth 33,
dashboard 92, commerce 81, solutions 54.

**Закрыто хорошо**: hero и navbar (все подвиды таксономии), pricing
(вплоть до калькулятора и промокода), auth (33 — исчерпывающе), dashboard
(закрывает почти всю группу «SaaS-экраны»: settings, billing, team-доступы,
notifications, integrations, API keys, empty, wizard, kanban, audit),
commerce (вся группа e-commerce). ai и solutions — вне классической
таксономии, это дифференциаторы каталога.

**Тонко (6–8 items, добить вариантами)**: testimonials, faq, cta, footer,
blog, contact.

**Съедено другими категориями (ок, но помнить при поиске)**: steps и stats
живут внутри features («Три шага», «Цифры достижений»), announcement bar —
внутри hero/navbar, newsletter — размазан по blog/hero/footer/cta,
onboarding — по dashboard/auth, booking — по contact/commerce/solutions.

**Дыры (нет вообще)**:

- P1 — error-pages (404/500/maintenance), team (маркетинговая секция),
  about/mission, logo-cloud как отдельная категория, newsletter отдельной
  категорией, case studies;
- P2 — changelog, roadmap, careers, comparison vs конкурентов,
  waitlist/coming-soon, cookie-consent, download/app badges;
- P3 — gallery/portfolio, events/webinars, video section, podcast,
  press kit, security/compliance (маркетинговая), partners/referral.

**Удалять нечего**: мусорных категорий нет. Вопрос вкуса — items вида
«Светлый первый экран» (светлая версия как отдельный item, а не контрол
темы) — оставить как есть, это осознанный приём каталога.

## Приоритизация для VibeUI (логика)

MVP-цепочка продукта — «собери лендинг за вечер», значит вес у групп 1–2:
hero, features, pricing, testimonials, FAQ, CTA, footer, navbar, logo cloud,
stats, steps, newsletter, contact — это 90% типового лендинга. Группа 4
(auth, dashboard, settings, empty, errors) — второй приоритет: вайбкодеры
строят SaaS. Группы 3 и 5 — по спросу. Группа 7 — приправа, дёшево даёт
«вау» (countdown, calculator, comparison).
