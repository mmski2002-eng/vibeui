# Картинки для сценария «Мобильное приложение»

Папка: `public/demo/app/`. Формат webp, качество 82. Без текста, водяных
знаков, логотипов и экранов с интерфейсом. Одна серия: спальня и окно,
мягкий свет, спокойные тона лаванды и синевы.

## Общий стиль (добавлять к каждому промпту)

```
Photorealistic calm lifestyle photograph, soft diffused light, muted
lavender and deep blue palette, clean modern bedroom, shallow depth of
field, no people's faces, no text, no watermark, no logos, no screens.
```

## Список

| Файл | Формат | Промпт |

## Куда что идёт

- `evening.webp` — подложка отзывов.
- `night.webp` — подложка CTA «скачать».
- `morning.webp` — резерв (галерея, соцсети).
