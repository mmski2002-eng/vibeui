# План сценария «Мобильное приложение»

Слаг: `app`. Демо: `/scenarios/app/demo`. Статус: собран из блоков (19 сентября 2026). Экраны приложения нарисованы CSS, фото — плейсхолдеры до генерации по `IMAGES.md`.

## Идея

**«Тише»** — приложение для сна и дыхания: вечерние ритуалы, дыхательные
практики, умный будильник. Сайт показывает не скриншоты, а живой телефон
из CSS: круг дышит вместе с вами, экраны переключаются по прокрутке,
график сна двигается ползунком «до / после». Всё, что обещает приложение,
можно потрогать до установки.

## Стиль

Светлая ночь: фон `#f4f2fb`, чернила `#1c1b2e`, **лаванда `#7c5cff`** —
акцент, второй фон `#ebe8f7`, ночной экран телефона `#151428`. Мягкие
градиенты, крупные скругления, стеклянные карточки. Типографика:
**Manrope** (заголовки и текст, кириллица родная), **IBM Plex Mono** —
цифры. Движение: дышащий круг, экраны по прокрутке, ползунок сравнения,
звёзды рейтинга, QR из CSS.
