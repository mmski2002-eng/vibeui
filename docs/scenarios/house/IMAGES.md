# Картинки для сценария «Дома из клеёного бруса»

Папка: `public/demo/house/`. Формат webp, качество 82. Без текста, водяных
знаков, логотипов. Одна серия, будто снимал один архитектурный фотограф:
северная природа (Карелия, Ладога, Подмосковье), сосны, гранит, вода,
**синий час / сумерки**, тёплый янтарный свет в окнах, холодное небо.
Дома — современные шале и барнхаусы из клеёного бруса медового тона,
панорамное остекление, тёмная кровля (фальц или битумная черепица),
террасы из лиственницы. Без людей, если промпт не просит.

## Общий стиль (добавлять к каждому промпту)

```
Premium architectural photography, glued laminated timber house, honey-toned
wood, large panoramic windows glowing with warm amber interior light, cold
blue-hour sky with dramatic clouds, northern pine forest, granite rocks,
cinematic, moody, deep shadows, high dynamic range but natural, shot on
Phase One, 35mm, straight verticals, no people, no text, no watermark,
no logos.
```
