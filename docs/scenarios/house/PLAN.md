# План сценария «Строительство домов из клеёного бруса»

Слаг: `house`. Демо: `/scenarios/house/demo`. Группа: `local`. Статус: собран
(15 октября 2026), фото от Codex по `IMAGES.md`. Референс: `photo_2026-10-15_12-00-44.jpg`
(концепт «Технострой», @h1lyaako1).

## Что на референсе

- Тёмный кинематографичный UI поверх фото: дом из бруса на скалистом
  берегу, сумерки, тёплый свет в окнах, сосны, озеро.
- Шапка: лого-домик «ТЕХНОСТРОЙ», меню (Проекты, Построенные дома,
  Банкетно-гостевые дома, Блог, Контакты), телефон, белая пилюля
  «Обсудить дом».
- Хиро: огромный тонкий гротеск «Строительство домов», подзаголовок
  «из клеёного бруса». Слева внизу — стеклянная карточка проекта: «КБ-242»,
  площадь, цена «21 780 000 ₽», «Смотреть проект», счётчик «01 / 04»
  и стрелки — хиро это слайдер проектов. Справа внизу — мелкая ссылка
  с иконкой (подбор проекта / каталог).
- Секция «Какой дом ваш?»: фильтры-чипы по площади (Все / до 150 м² /
  150–200 м² / более 200 м²), кнопка «Все проекты (26)», счётчик найденных.
  Карточки 2 в ряд: большое фото, код (КБ-86, КБ-160), площадь · этажи ·
  спальни, цена «под ключ / домокомплект», «Смотреть проект ↗».
- Типографика: тонкий широкий гротеск, моно-цифры цен, много воздуха,
  скругления ~16px, белые пилюли-кнопки на тёмном.

## Идея

**«Сосна»** (рабочее имя, не «Технострой» — чужой бренд) — компания,
которая строит дома из клеёного бруса под ключ. Продаёт не стройку,
а готовый образ жизни: дом у воды в сумерках. Сайт — каталог проектов
с ценой сразу на карточке, путь «выбрал проект → понял цену → обсудил».

## Стиль

«Вечерний лес»: фон `#0e0f10` / графит `#17191b`, текст `#f2efe9`,
акцент — тёплый свет окна `#e8a35c` (точечно: цены, активный чип,
прогресс). Стекло `rgba(23,25,27,.6)` + blur для карточек поверх фото.
Шрифты: Manrope (тонкий 300 для заголовков), JetBrains Mono для цен
и кодов проектов. Тема `tone: "dark"`.

## Фото

Плейсхолдеры в `public/demo/house/`, одна серия: дома из клеёного бруса,
северная природа, сумерки, тёплый свет окон. Хиро — 4 кадра 16:9, каталог —
6–8 кадров 4:3, технология — 1 макро бруса, построенные — 4 пары
«стройка/готово». Промпты — в `IMAGES.md` (писать после согласования).

## Кросс-блочное

`house-001` и `hero-049` — «Смотреть проект» с `id` проекта;
`house-002` → `cta-038` через `vibeui-house:estimate` (имя события — проп).

## Чек-лист сборки

По `docs/PIPELINE.md`: `npm run item -- <category>` на каждый блок,
палитра `--vibeui-<name>-*`, `prefers-reduced-motion`, metadata + `i18n.en`,
запись в `registry/scenarios.ts` (slug `house`), демо-страницы
`app/scenarios/house/demo` и `app/en/scenarios/house/demo`,
`npm run meta:validate`, проверка в браузере mobile / tablet / desktop.
