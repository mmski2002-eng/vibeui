# План сценария «Благотворительный фонд»

Слаг: `charity`. Демо: `/scenarios/charity/demo`. Статус: собран из блоков (19 сентября 2026). Фото: 8 плейсхолдеров в `public/demo/charity/`, промпты в `IMAGES.md`.

## Идея

**«Тёплый дом»** — фонд помощи одиноким пожилым людям: продукты, визиты
соцработника, ремонт, «просто поговорить». Сайт говорит честно и тепло,
без жалости: живые цифры сбора, письма подопечных от руки, отчёт «куда
ушёл каждый рубль» и «0 % на рекламу». Всё, что может быть бумагой, —
бумага: карточки-письма, конверты, пометки Caveat на полях.

## Стиль

Бумага `#f6f1ea`, чернила `#2b211b`, **терракот `#c2410c`** — акцент,
горчица — вторая краска (выводится из акцента через `color-mix`).
Типографика: **Playfair Display** (заголовки, антиква), **Golos Text**
(текст), **Caveat** (рукописные пометки, подписи, суммы «от руки»).
Зерно бумаги через `feTurbulence`. Движение: строки заголовка выезжают из
масок, счётчик сбора докручивается, прогресс заполняется с вехами,
магнитная кнопка, конверты раскрываются, письмо печатается, кольцевая
диаграмма рисуется, точки на карте зажигаются по очереди.
