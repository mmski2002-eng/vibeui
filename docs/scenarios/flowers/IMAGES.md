# Картинки для сценария «Цветочная мастерская»

Папка: `public/demo/flowers/`. Формат webp, качество 82. Без текста, водяных
знаков, логотипов. Одна серия: мастерская в бывшей аптеке — кафель, дуб,
крафтовая бумага, дневной свет из витринного окна; цветы сезонные, без
целлофана и бантов.

## Общий стиль (добавлять к каждому промпту)

```
Editorial botanical photograph, natural daylight from a shop window,
warm paper-toned palette (#f3efe6 background, ink-dark shadows, one poppy
red accent), kraft paper wrapping, no cellophane, no ribbons, shallow depth
of field, film grain, no text, no watermark, no logos, no faces in focus.
```
