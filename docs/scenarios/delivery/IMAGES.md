# Картинки для сценария «Доставка еды / дарк-китчен»

Папка: `public/demo/delivery/`. Формат webp, качество 82. Все кадры
квадратные — на сайте они режутся в круг, каплю и блоб, поэтому блюдо
должно стоять по центру с запасом по краям. Фон однотонный тёмный
(уголь, почти чёрный), еда сочная, чуть переэкспонированная, «нагло»
аппетитная. Без текста, логотипов, рук и лиц.

## Общий стиль (добавлять к каждому промпту)

```
Top-down or 30-degree food photograph on a matte charcoal black surface,
hard directional studio light with a warm rim, saturated juicy colours,
slight steam, glossy sauce highlights, dish centred with generous margin
on every side, no text, no logos, no hands, no watermark.
```
