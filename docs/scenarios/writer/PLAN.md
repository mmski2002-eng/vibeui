# План сценария «Личный сайт писателя»

Слаг: `writer`. Демо: `/scenarios/writer/demo`. Статус: собран из блоков (19 сентября 2026). Фото: три плейсхолдера.

## Идея

**«Вера Холодова: тексты и книга»** — сайт эссеистки как читалка: ничего,
кроме текста, набранного так, чтобы его хотелось читать. Сайт живёт в двух
состояниях — «ночь» (тёплый графит) и «бумага» (день); переключатель в шапке
и на первом экране меняет весь сайт разом: каждый блок слушает событие
`vibeui-writer:theme` и плавно кроссфейдится. Книга стоит на полке в 3D и
открывается на первую страницу, архив текстов раскрывается прямо в списке,
фрагмент эссе читается с закладкой-прогрессом и сносками на полях.

## Стиль

Читалка: ночь — фон `#17161a`, текст `#ece5d8`; день — бумага `#f4efe6`,
чернила `#1f1c19`; **сепия `#d9a066`** — акцент (чернильные подчёркивания,
закладка, перо). Оба состояния заданы через `light-dark()` в пропсах, блок
переключает `color-scheme` по событию. Типографика: **Cormorant Garamond**
(имя, заголовки, до 7rem), **PT Serif** (текст, курсивные подписи), для
заметок на полях — **Caveat**. Колонка текста 65 символов, буквицы,
вертикальный ритм 1.7. Движение: строки въезжают с маской, цитата
печатается пером, обложка открывается, чернила подчёркивают фразы, заметки
на полях сменяются. Всё на CSS + React, без библиотек.

## Секции → блоки

| # | Блок | Роль и фишка |
| --- | --- | --- |
| 1 | `navbar-045` | Имя набором антиквы, «тексты · книга · письма», солнце/луна (шлёт `vibeui-writer:theme`), бургер; по низу — чернильная линия прогресса чтения страницы. |
| 2 | `hero-045` | Имя огромной антиквой, строки въезжают из-под маски; «сегодняшняя строка» — цитата печатается буква за буквой с курсором-пером и сменяется; солнце/луна с кроссфейдом всего сайта. |
| 3 | `writer-001` | Книга: 3D-обложка (perspective, корешок, тень), при наведении открывается на первую страницу с буквицей; «бумага / электронная / аудио» меняет цену и кнопку; полоса «прочитано читателями: N страниц» тикает. |
| 4 | `writer-002` | Архив текстов: крупные заголовки, при наведении выезжают год и время чтения, за курсором ходит превью с первой строкой; фильтр по темам; «читать дальше» раскрывает фрагмент с буквицей прямо в списке. |
| 5 | `writer-003` | Чтение по прокрутке: фрагмент эссе колонкой 65ch, закладка-прогресс сбоку, сноски на полях проявляются при доскролле (IntersectionObserver), выделенные фразы подчёркиваются чернилами (background-size). |
| 6 | `bento-014` | О себе: bento из плиток разного размера — портрет, цифры, которые докручиваются в viewport, маршрут городов, факт, «сейчас пишу» с полосой черновика, рабочий стол. |
| 7 | `writer-004` | Отзывы читателей как заметки на полях: страница с фрагментом в центре, вокруг — рукописные заметки с ротацией, сменяются по кругу. |
| 8 | `event-026` | Встречи: презентация, чтения, эфир — лента дат от сегодняшнего дня (`useSyncExternalStore`), «до ближайшей — N дней», прошедшие вычёркиваются. |
| 9 | `subscribe-020` | Письма читателям: выбор частоты (раз в неделю / раз в месяц) меняет обещание, одно поле — одна кнопка, галочка прорисовывается пером; рядом конверт прошлого письма, который открывается. |
| 10 | `contact-033` | Для издателей: агент, права, пресс-кит; почта копируется в один клик с подтверждением. |
| 11 | `footer-044` | Подвал-колофон: имя, разделы, соцсети, «набрано Cormorant и PT Serif», «наверх». |

Все 11 блоков новые. `testimonials-037` и остальные зарезервированные
имена (`cta-038`, `stats-014`, `about-026`, `blog-027`) не понадобились:
отзывы сделаны в своей категории (`writer-004`), чтобы не плодить slots.
