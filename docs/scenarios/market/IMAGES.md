# Картинки для сценария «Маркетплейс цифровых товаров»

Папка: `public/demo/market/`. Формат webp, качество 82, все обложки 4:3,
1200×900. Без текста, водяных знаков, логотипов, интерфейсов с реальными
брендами. Одна серия: обложки цифровых товаров как их рисуют для магазина
ассетов — абстрактные градиенты, мягкие объёмные формы, много воздуха,
один цвет доминирует. Сейчас на месте каждой — градиентный плейсхолдер.

## Общий стиль (добавлять к каждому промпту)

```
Product cover for a design-asset marketplace, abstract composition,
smooth gradient background, soft studio lighting, clean minimal layout
with lots of empty space, subtle grain, no text, no watermark, no logos,
no real UI screenshots, 4:3.
```
