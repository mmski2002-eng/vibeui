# План сценария «Подкаст»

Слаг: `podcast`. Демо: `/scenarios/podcast/demo`. Статус: собран из блоков (19 сентября 2026), фото — плейсхолдеры до генерации по `IMAGES.md`.

## Идея

«Тихий час» — подкаст о том, как люди работают: разговоры с теми, кто делает
своё дело руками и головой. Сайт — это студия ночью: тёмный, тихий, с одним
кислотным акцентом, как индикатор записи. Всё, что звучит, — видно: волна
эпизода, бегущие цитаты, счётчик минут.

## Стиль

Тёмная тема по умолчанию: уголь `#0e0d12`, панель `#17161d`, текст
`#f3efe6`, **кислотный лайм `#c8f542`** — единственный акцент («на записи»).
Типографика: **Sofia Sans Extra Condensed** (заголовки-плакаты, узко и
высоко), **Inter Tight** (текст), **IBM Plex Mono** (таймкоды, номера
эпизодов). Движение: волна эпизода, бегущие строки цитат в разные стороны,
count-up статистики, мини-плеер выезжает снизу.
