# Картинки для сценария «Онлайн-курс»

Папка: `public/demo/course/`. Формат webp, качество 82, длинная сторона
1600px (портреты 1024×1280). Без текста, водяных знаков и логотипов.
Одна серия: светлые студии и рабочие места, естественный свет.

## Общий стиль (добавлять к каждому промпту)

```
Photorealistic editorial photograph, bright natural daylight, clean modern
workspace, soft neutral palette with a hint of indigo, shallow depth of
field, no text, no watermark, no logos, no visible screen content.
```
