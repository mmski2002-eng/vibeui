# Картинки для сценария «AI-инструмент / SaaS»

Папка: `public/demo/saas/`. Сайту фото **не нужны**: аврора, стекло и
интерфейсы нарисованы CSS. Единственный необязательный файл — обложка
для соцсетей.

## Общий стиль

```
Abstract 3D render, deep navy background, aurora gradient light (cyan,
violet, pink) refracted through frosted glass panels, soft bloom, no text,
no watermark, no logos.
```

## Список

| Файл | Формат | Промпт |
| --- | --- | --- |
| `og.webp` | 1200×630 | Three stacked frosted glass cards floating over a navy void, an aurora light passing through them from behind, one cyan highlight |

## Куда что идёт

- `og.webp` — только Open Graph превью (в блоках не используется).
