# План сценария «AI-инструмент / SaaS»

Слаг: `saas`. Демо: `/scenarios/saas/demo`. Статус: собран из блоков (19 сентября 2026). Фото не нужны.

## Идея

**«Сводка»** — AI, который превращает созвоны в решения: расшифровка →
итоги → задачи в трекере. Сайт сам является демо: на первом экране
ассистент печатает сводку по расшифровке, в песочнице можно вставить свой
текст и получить итоги, интеграции кружат по орбите, цена считается
ползунком мест.

## Стиль

Тёмная «аврора»: фон `#0a0f1e`, панели-стекло, текст `#eef2ff`,
**циан `#5ee7ff`** — акцент, аврора-градиент (циан → фиолет → розовый) в
пятнах и в заголовках. Типографика: **Wix Madefor Display** (заголовки),
**Golos Text** (текст), **IBM Plex Mono** (токены, цифры). Движение:
потоковая печать ответа, бегущие точки по конвейеру, орбиты интеграций,
ползунок мест, стекло с бликом.
