# Картинки для сценария «Автосервис / детейлинг»

Папка: `public/demo/auto/`. Формат webp, качество 82. Без текста, водяных
знаков, логотипов и номерных знаков. Одна серия: закрытый детейлинг-бокс
ночью, графитовые стены, тёплые софиты, влажный блеск лака, оранжевые
акценты (перчатки, лента, лампа).

## Общий стиль (добавлять к каждому промпту)

```
Photorealistic automotive detailing studio at night, dark graphite walls,
warm LED softbox lighting, wet-look glossy paint, subtle orange accents,
cinematic contrast, shallow depth of field, no text, no watermark, no logos,
no license plates, no visible brand badges.
```
