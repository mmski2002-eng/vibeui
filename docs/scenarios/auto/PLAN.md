# План сценария «Автосервис / детейлинг»

Слаг: `auto`. Демо: `/scenarios/auto/demo`. Статус: собран из блоков (19 сентября 2026), в браузере не проверялся — по правилу заказчика проверка глазами за координатором. Фото: 9 плейсхолдеров в `public/demo/auto/`.

## Идея

**«Гараж 42»** — детейлинг-студия в закрытом боксе на Обводном: керамика,
антигравийная плёнка, полировка, химчистка. Сайт продаёт результат и
прозрачность: силуэт машины на первом экране подсвечивает услугу с ценой
по зонам, калькулятор считает стоимость и время на лету и уносит выбор в
запись, до/после тянется шторкой, запись — по реальным слотам недели от
сегодняшнего дня.

## Стиль

Тёмный «гараж ночью»: графит `#0f1114`, секции через одну на `#14171b`,
текст `#f2f3f5`, **один кислотный оранжевый `#ff5a1f`** — акцент, заливки
зон, счётчики, лента марок. Типографика: **Unbounded** (заголовки капсом,
цифры), **Inter Tight** (текст), **JetBrains Mono** (ярлыки, слоты, часы).
Движение: прорисовка svg-контура, строки заголовка из масок, магнитная
кнопка, spotlight по курсору, 3D-tilt карточек, прогресс по прокрутке,
бегущие ленты, счётчики, зерно feTurbulence.

## Кросс-блочная связь

`auto-001` → `window.dispatchEvent(new CustomEvent("vibeui-auto:book", { detail: { services, carClass, total, minutes } }))` → `auto-004` показывает выбор в панели заказа. Имя события — проп `eventName` у обоих.
