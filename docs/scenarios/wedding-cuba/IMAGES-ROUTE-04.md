# Довесок: `route-04.webp` для сценария «Свадьба путешественников на Кубе»

Один файл, добавляется к уже готовой серии из
[IMAGES.md](IMAGES.md). Папка: `public/demo/wedding-cuba/`. Формат webp,
качество 82, квадрат 1024×1024. Без текста, водяных знаков и логотипов.
Та же серия: плёночный look (Kodak Ektar / Portra 160). Пара в дорожной
одежде — свадьбы ещё не было: **никаких свадебных платьев, костюмов, фаты,
букетов, колец крупным планом**.

Где стоит: остановка «IST · Стамбул · Май 2023 · Первая пересадка» в блоке
маршрута (`about-012`), круглая обрезка — лица ближе к центру кадра.

## Герои

```
Sonya: woman, 30, Slavic features, short dark bob with bangs, sun-kissed
skin, no heavy makeup.
Timur: man, 32, Slavic features, dark curly hair, stubble, canvas backpack.
```
