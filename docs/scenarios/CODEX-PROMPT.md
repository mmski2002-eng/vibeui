# Промпт для Codex: фото для девяти новых сценариев

Скопировать целиком и отправить Codex в репозитории VibeUI.

---

Сгенерируй фотографии для девяти сценариев-сайтов VibeUI и положи их на место
плейсхолдеров. Ничего в коде не менять — только перезаписать webp-файлы.

**Что делать по каждому сценарию.** Открой `docs/scenarios/<slug>/IMAGES.md`:
там папка назначения, общий стиль (добавлять к каждому промпту), таблица
«файл | формат | промпт» (промпт на английском) и «куда что идёт».
Сгенерируй каждую картинку по своему промпту + общему стилю, приведи к
указанному формату и размеру, сохрани как webp качества 82 и перезапиши
файл с тем же именем в `public/demo/<slug>/`. Сейчас там лежат цветные
градиенты-заглушки того же имени и размера — ориентируйся на них по
пропорциям.

**Общие правила для всех.**
- Без текста, водяных знаков, логотипов, интерфейсов на экранах.
- Фотореализм, естественный свет, если в стиле сценария не сказано иное.
- Люди — только если промпт прямо просит; лица разные, реалистичные,
  не стоковые улыбки. Один и тот же человек должен быть узнаваем, если он
  встречается в нескольких кадрах одного сценария (см. секцию «Герои» в
  IMAGES.md, где она есть).
- Соблюдать палитру сценария из «Общего стиля»: все кадры одного сайта —
  одна серия, снятая как будто одним фотографом.
- Формат и размер — строго из таблицы (16:9 1600×900, 3:2 1600×1067,
  1:1 1200×1200, 4:5 1024×1280 и т. п.). Не кропать неожиданно: у
  портретов голова целиком, у блюд — тарелка целиком.
- Имя файла — ровно как в таблице, расширение `.webp`, качество 82.

**Порядок.** Идти по сценариям сверху вниз, по одному, после каждого —
короткий отчёт: сколько файлов записано, что не удалось. Не начинать
следующий сценарий, пока предыдущий не закрыт целиком. Ничего не
коммитить и не пушить — это сделаем отдельно после просмотра.

`fintech`, `api`, `gadget`, `opensource`, `saas` — фото не нужны (всё CSS),
их пропустить. `bakery`, `podcast`, `portfolio`, `app` — уже готовы, не
трогать.
