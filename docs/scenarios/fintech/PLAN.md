# План сценария «Финтех / банк для малого бизнеса»

Слаг: `fintech`. Демо: `/scenarios/fintech/demo`. Статус: собран из блоков (19 сентября 2026). Фото не нужны.

## Идея

**«Ось»** — необанк для малого бизнеса: счёт за 10 минут, переводы по
СБП без комиссии, налоги считаются сами, карты сотрудникам, 1С и
маркетплейсы подключены. Сайт ведёт себя как приложение: банковская карта
на первом экране поворачивается за курсором и по ней «бегут» живые
операции, дашборд рисует график при появлении, калькулятор считает
экономию на комиссиях, а секция безопасности проводит карту сквозь четыре
слоя защиты по прокрутке.

## Стиль

Глубокий индиго/чёрный `#07091a`, «северное сияние» из **зелёного
`#4ade80`** и мяты в размытых пятнах, стекло с бликом и тонкие линии
(сетка, рамки 1px). Текст `#e8ecf8`. Типографика: **Wix Madefor Display**
(заголовки, плотный tracking), **Inter Tight** (текст), **IBM Plex Mono**
с `tabular-nums` (все цифры: балансы, суммы, счётчики). Движение —
ease-out, только transform/opacity, всё выключается `prefers-reduced-motion`.

## Фирменные приёмы

1. Хиро: 3D-карта (perspective) поворачивается за курсором, блик следует
   за ним, номер маскируется и открывается по кнопке, справа от карты
   всплывают «живые» операции; одно градиентное слово в заголовке.
2. «Живой баланс»: SVG-area рисуется при появлении в viewport, операции
   появляются по одной, переключатель день / неделя / месяц морфит линию
   и докручивает баланс.
3. Калькулятор экономии: слайдер оборота → «сэкономите N ₽/год»
   анимированным счётчиком, сравнение с двумя условными банками полосами.
4. Сканирующая безопасность: sticky-сцена, по прокрутке карта проходит
   четыре слоя защиты, активный слой подсвечивается, иконка-линия
   прорисовывается.
5. Тарифы: переключатель старт / рост / масштаб + слайдер сотрудников,
   «бесплатно до N операций».
6. Бегущая строка интеграций + счётчики «компаний / переводов сегодня»
   от текущего времени.
