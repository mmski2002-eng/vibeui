# План сценария «Портфолио разработчика / дизайнера»

Слаг: `portfolio`. Демо: `/scenarios/portfolio/demo`. Статус: собран из блоков (19 сентября 2026), фото — плейсхолдеры до генерации по `IMAGES.md`.

## Идея

Даня Лунёв — фронтенд-разработчик и дизайнер интерфейсов, работает с
командами на ранней стадии. Сайт — одна длинная страница, которая ведёт
себя как живой человек: следит за курсором пятном света, знает своё
местное время, печатает роли по очереди, а проекты складываются стопкой
по мере прокрутки. Никаких «сеток из шести карточек».

## Стиль

Бумага `#efeee9`, чернила `#141414`, **ультрафиолет `#5b3df5`** — акцент,
второй фон `#e6e4dc`. Типографика: **Inter Tight 800** (огромные
заголовки, плотный трекинг), **Golos Text** (текст), **IBM Plex Mono**
(подписи, время, теги). Движение: пятно света за курсором, печатающиеся
роли, магнитные кнопки, стопка проектов на sticky, бегущая строка
компаний, фото из ч/б в цвет по наведению, автопрокрутка цитат с полосой.
