# Картинки для сценария «Портфолио разработчика / дизайнера»

Папка: `public/demo/portfolio/`. Формат webp, качество 82. Без текста,
водяных знаков, логотипов и читаемых интерфейсов. Одна серия: дневной
свет, нейтральный современный интерьер, чистые поверхности.

## Герой

```
Danya: man, 29, Slavic features, short dark curly hair, light stubble,
round thin glasses, black crew-neck tee, calm friendly expression, sits
at a plain desk with a laptop closed, window light from the side.
```

## Общий стиль (добавлять к каждому промпту)

```
Photorealistic editorial photograph, soft daylight, neutral off-white
interior, muted colours with one ultraviolet (#5b3df5) object in frame,
shallow depth of field, no text, no watermark, no logos, no readable
screens.
```
