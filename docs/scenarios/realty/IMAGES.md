# Картинки для сценария «Агентство недвижимости»

Папка: `public/demo/realty/`. Формат webp, качество 82, длинная сторона
1600px (портреты агентов 1280). Без текста, водяных знаков и логотипов.
Одна серия: один город, один сезон, один фотограф.

## Общий стиль (добавлять к каждому промпту)

```
Photorealistic architectural and interior photograph, editorial real estate
style, natural daylight, wide-angle but undistorted, calm muted palette with
warm neutrals and deep green accents, no people unless stated, no text, no
watermark, no logos, Saint Petersburg, Russia.
```
