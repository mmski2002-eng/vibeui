# План сценария «Ремонт квартир / строительная бригада»

Слаг: `renovation`. Демо: `/scenarios/renovation/demo`. Статус: собран из блоков (19 сентября 2026). Фото: 8 плейсхолдеров.

## Идея

**«Ровно»** — бригада, которая продаёт не «красиво», а «честно и в срок»:
фиксированная смета в договоре, календарь этапов, стройка в телефоне
заказчика. Сайт выглядит как рабочий чертёж: план квартиры рисуется
линиями на первом экране, смета считается ползунком и уходит прямо в форму
заявки, этапы едут по диаграмме Ганта при прокрутке, объекты сравниваются
шторкой «до/после», а карточка «стройка онлайн» обновляется от сегодняшней
даты.

## Стиль

«Чертёж»: два листа — светло-серый бетон `#eceae5` для основного тела и
тёмно-синяя миллиметровка `#0e1c36` для хиро, стройки онлайн и подвала.
На всех фонах чертёжная сетка (CSS `background-image`: крупная клетка 5rem
и мелкая 1rem), тонкие линии с размерами, штампы-рамки. Акцент —
**сигнально-жёлтый `#ffd60a`**, текст `#141a24` / `#eef2f7`. Типографика:
**Inter Tight** (заголовки, плотный tracking), **Onest** (текст),
**JetBrains Mono** (цифры, подписи, штампы), Caveat — только «подпись
заказчика» в актах. Движение: прорисовка линий (stroke-dashoffset),
докручивание чисел (rAF), scroll-driven маркер по Ганту, шторка сравнения,
пульс камеры, штамп «ставится» через `animation-timeline: view()`.

## Кросс-блочное

`renovation-001` → `window.dispatchEvent(new CustomEvent("vibeui-renovation:estimate", { detail }))`,
`cta-030` слушает то же имя (`eventName`) и показывает смету чипом. Имя
события — проп в обоих блоках.
