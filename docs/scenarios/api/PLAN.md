# План сценария «API / dev-tool с оплатой за запросы»

Слаг: `api`. Демо: `/scenarios/api/demo`. Статус: собран из блоков (19 сентября 2026). Фото не нужны.

## Идея

**«Геокод»** — API геокодирования: адрес → координаты, обратный геокодинг,
маршруты, подсказки адресов. Оплата за запросы, бесплатно до 10 000 в
месяц. Сайт — «терминал, но красивый»: на первом экране запрос печатается
сам, а ответ приходит с подсветкой и задержкой «42 ms»; в песочнице можно
ввести адрес и увидеть точку на стилизованной карте; цена считается
логарифмическим ползунком с лестницей порогов; статус-панель живёт от
текущего времени; сравнение раскрывает пример ответа по клику на строку.

## Стиль

Тёмный терминал: фон `#0b0d10`, текст `#e6edf3`, **фосфорный `#7cf3a0`** —
единственный акцент (янтарный `#ffb454` — только для статуса «деградация»
внутри статус-панели). Сетка-точки на фоне секций, тонкие рамки 1px на
12% текста, панели на 4% текста, «лампочки» статуса с пульсом.
Типографика: **Inter Tight** (заголовки и текст, плотный tracking) +
**JetBrains Mono** (код, пути эндпоинтов, метрики, версии). Скругления
0.6–1rem, без теней — только линии и свечение акцента. Движение:
печать кода, приход JSON построчно, точка на карте, лестница цен,
спарклайн, который прорисовывается, раскрытие строк через
`grid-template-rows`, счётчики, генерация ключа.
