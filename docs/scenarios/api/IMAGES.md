# Картинки для сценария «API / dev-tool с оплатой за запросы»

Папка: `public/demo/api/`. Сайту фото не нужны: карта, терминал, графики и
лампочки — CSS и SVG внутри блоков. Плейсхолдеры не генерировались.

Единственная необязательная картинка — OG-обложка для соцсетей, если
сценарий будут расшаривать. Формат webp, качество 82.

## Общий стиль

```
Dark developer-tool aesthetic, near-black background #0b0d10, subtle dot
grid, thin 1px borders, a single phosphor-green accent #7cf3a0, monospace
UI fragments (JSON, latency badges), no people, no text overlays, no
watermark, no logos.
```

## Список

| Файл | Формат | Промпт |
| --- | --- | --- |
| `og.webp` | 1.91:1, 1200×630 | A stylized dark map made of a dot grid with faint street lines and a ring road, a single glowing phosphor-green pin with a ripple, a small floating monospace panel fragment showing a JSON snippet, cinematic depth, ultra clean |

## Куда что идёт

- `og.webp` — только `openGraph.images` в metadata страницы, если понадобится. В блоках не используется.
