# План сценария «Хардвер-гаджет»

Слаг: `gadget`. Демо: `/scenarios/gadget/demo`. Статус: собран из блоков (19 сентября 2026). Фото не нужны.

## Идея

**«Луч»** — умная настольная лампа-будильник: за 30 минут до звонка свет
разгорается от углей до дневного белого, динамик подхватывает птицами,
датчики следят за воздухом и светом в комнате. Сайт — продуктовый лендинг
уровня Apple / Teenage Engineering: сам гаджет нарисован CSS, он же герой
каждой сцены. Лампа на первом экране реально светит — ползунки «тёплый ↔
холодный» и «яркость» меняют свет через CSS-переменные, и заголовок
проявляется вместе с ним.

## Стиль

Почти чёрный `#0a0a0a` → тёплый белый `#f4efe6` → снова чёрный: страница
проходит «ночь → утро → вечер» по секциям, а внутри сцены рассвета комната
светлеет по прокрутке. Акцент — тёплый янтарь `#ffb454` (свет лампы), на
светлых секциях — глубокий `#d4780f`. Типографика: **Unbounded** (гигантские
заголовки, clamp до 6rem), **Inter Tight** (текст), **JetBrains Mono**
(техно-подписи: кельвины, люмены, время). Движение: маски-въезды строк,
свет по переменным, sticky-рассвет, взрыв-схема, дуги SVG, докрутка цифр,
бегущая строка, магнитная кнопка. Всё CSS + React, без библиотек.
