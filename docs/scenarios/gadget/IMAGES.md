# Картинки для сценария «Хардвер-гаджет»

Папка: `public/demo/gadget/`. Сайту фото не нужны: лампа, комната и свет
нарисованы CSS, все блоки сценария работают без единой картинки. Папка
не создаётся. Единственный необязательный файл — обложка для соцсетей.

## Общий стиль (добавлять к промпту)

```
Photorealistic product photograph, matte black studio background, single
warm amber light source, no text, no watermark, no logos, no people.
```

## Список

| Файл | Формат | Промпт |
| --- | --- | --- |
| `og.webp` | 1200×630 | A minimalist smart desk lamp shaped like a short matte graphite cylinder with a glowing opal disc on top, warm amber light spilling onto a dark wooden desk, deep black background, cinematic rim light, centered composition with empty space on the right |

## Куда что идёт

- `og.webp` — только `metadata.openGraph` страницы, если понадобится превью
  ссылки. В блоках не используется.
