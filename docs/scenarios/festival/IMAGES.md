# Картинки для сценария «Городской фестиваль»

Папка: `public/demo/festival/`. Формат webp, качество 82, длинная сторона
1600px (портреты и квадраты 1024). Без текста, водяных знаков и логотипов.
Одна серия: солнечный летний город, яркие чистые цвета, много воздуха.
Сайт белый с цветными капсулами — фото должны быть сочными, но не
перегруженными: один-два ярких цвета в кадре, остальное нейтральное.

## Общий стиль (добавлять к каждому промпту)

```
Photorealistic editorial photograph, bright summer daylight, vivid but clean
colours (lime, coral, cobalt, peach accents), city festival atmosphere,
happy diverse people, shallow depth of field, no text, no watermark, no
logos, no readable signage.
```
