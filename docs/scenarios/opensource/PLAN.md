# План сценария «Open-source проект»

Слаг: `opensource`. Демо: `/scenarios/opensource/demo`. Статус: собран из блоков (19 сентября 2026). Фото не нужны.

## Идея

**tabl** — headless-таблица для React на 4 КБ: сортировка, группировка,
виртуализация, без стилей. Сайт — как README, который ожил: команда
установки копируется, терминал печатает сам, песочница показывает код и
результат рядом и меняется от переключателей, размер бандла сравнивается
живыми полосами, история версий раскрывается по клику.

## Стиль

Светлая «инженерная» тема: бумага `#fbfbf9`, чернила `#111111`, линии
`#e6e5e1`, **электрик `#2f5bff`** — акцент, терминал тёмный `#0f1117` с
зелёным `#7ee787`. Клетчатая подложка (сетка 24px). Типографика: **Onest**
(текст и заголовки, кириллица родная) + **JetBrains Mono** (код, команды,
версии). Острые углы 6px, без теней — только линии. Движение: печатающийся
терминал, count-up звёзд, полосы размера, раскрытие версий, звезда, которая
заливается на hover.
